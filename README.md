💡 My Approach

For every problem, I try to follow this process:

Understand the Problem
        ↓
Identify the Pattern
        ↓
Think of a Brute-Force Solution
        ↓
Optimize the Approach
        ↓
Write Clean Code
        ↓
Analyze Time & Space Complexity
        ↓
Document the Solution

The goal is not just to solve the problem, but to understand why the solution works.
